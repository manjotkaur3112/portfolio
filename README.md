# 💻 Installation

Clone the repository

```bash
git clone https://github.com/manjotkaur3112/portfolio.git
```

Move into project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build project

```bash
npm run build
```
